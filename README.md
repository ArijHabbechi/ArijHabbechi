### 🔍 What I Build

I work at the intersection of **Kubernetes security**, **eBPF-based observability**, and **platform automation** — designing infrastructure that doesn't just run, but tells you exactly what it's doing at the kernel level.

- 🔐 Kubernetes security platforms: image scanning, runtime threat detection, compliance visibility
- 📡 Centralized observability pipelines: Prometheus · OpenSearch · Fluent Bit · Telegraf
- ⚡ eBPF-native tooling: custom Tetragon policies for control plane threat detection
- 🔒 Identity-aware network policies with Cilium + real-time L3/L4/L7 visibility via Hubble
- 🚀 Secure CI/CD pipelines: SAST · DAST · image scanning · policy-as-code baked in from the start
